## 1. コンセプト

### 1.1 元になる逸話
達磨大師は梁の武帝との問答のあと、一本の葦の葉に乗って長江を渡り、北の魏へ向かったと伝えられています（一葦渡江）。このゲームはその場面を題材にしています。

### 1.2 どんな体験にするか
- ブラウザで開いてすぐ遊べる。インストールや登録は不要
- 1回のプレイは **30秒〜2分程度**。何度もやり直したくなる短さにする
- 操作は「左右に動かす」だけ。説明を読まなくても遊べる
- 見た目は **水墨画風**（墨の濃淡、和紙の白、達磨の衣だけが朱色）
- 遊び終わると逸話を短く知ることができ、長岡念珠店につながる

### 1.3 位置づけ
長岡念珠店のコンテンツ（SNSで共有して遊んでもらう入口）。売り込みは強くしない。

- スマホブラウザ（iPhone Safari / Android Chrome）

## 3. 画面の構成と流れ

```
タイトル画面 → プレイ画面 → 結果画面 → （もう一度 / タイトルへ）
```

### 3.1 タイトル画面
- 背景：霧がかった長江の水面。葦の葉に乗った達磨が、静かに揺れている（3Dで動いている状態）
- 表示：タイトル「一葦渡江」、小さく読み「いちいとこう」
- 「はじめる」ボタン（画面のどこをタップ／クリックしても開始でよい）
- 右下に小さく「長岡念珠店」の表記
- 音のオン／オフ切り替え（第7章）

### 3.2 プレイ画面
- カメラは達磨の **後ろ斜め上** から、進行方向（川の上流から下流ではなく、対岸＝北へ向かう方向）を見る
- 達磨を乗せた葉は自動で前へ進み続ける。プレイヤーは左右だけを操作する
- 画面上部に進んだ距離を表示（単位は「里」などの雰囲気のある表記。【未決定】）
- 距離の横に、拾った珠の数を「珠 23／108」の形で表示（4.6）
- 一時停止ボタン（右上）

### 3.3 結果画面
- 進んだ距離と、拾った珠の数・完成した念珠の数（と、それぞれのベスト記録）
- 一葦渡江の逸話の紹介文（2〜3行）。【未決定：文面】仮の文面は次のとおり（長岡が確認・修正する）
  > 達磨大師は、梁の武帝との問答ののち、一本の葦の葉に乗って長江を渡り、北の魏へ向かったと伝えられます。この「一葦渡江」の姿は、禅画の題材として今も描き継がれています。
- ボタン：「もう一度」「Xで共有」「長岡念珠店のサイトへ」
- ベスト記録はブラウザに保存する（別の端末とは共有しない）

## 4. ゲームのルール

### 4.1 操作
| 環境 | 操作 |
|---|---|
| PC | ← → キー、または A / D キー。マウスを左右に動かしても追従する |
| スマホ | 画面を左右にドラッグ（指の位置に向かって葉が流れるように寄っていく） |

- 葉は「ピタッ」とは動かず、水に乗っているように **少し遅れて滑らかに** 動く
- 左右に動くと、葉と達磨が進行方向に少し傾く
- スマホの傾きセンサー操作：【未決定】（仮：今回は入れない）

### 4.2 前進とスピード
- 葉は自動で前進する
- 時間とともに少しずつ速くなる
- 川の流れは一定ではなく、場所によって横向きの流れがあり、葉が勝手に左右へ押される（流れは水面の模様で見えるようにする）

### 4.3 障害物
| 名前 | 見た目 | ぶつかる・入るとどうなるか |
|---|---|---|
| 岩 | 水面から突き出た黒い岩 | ぶつかると転覆（4.4） |
| 流木 | 横向きに流れてくる木 | ぶつかると転覆 |
| 渦 | 水面の渦巻き | 近づくと中心へ引き寄せられ、中心に入ると転覆。うまく横切れば抜けられる |
| 大波 | 前方から来る白い波 | 葉が大きく揺れて、数秒間 左右操作が効きにくくなる（転覆はしない） |

- 最初の10秒ほどは岩だけ、まばらに出す（慣れてもらうため）
- 進むほど障害物の数と種類が増える
- 出現の並びは毎回ランダム。ただし **必ずどこかに通り抜けられる道がある** ようにする

### 4.4 転覆と「七転び八起き」
- ぶつかると達磨が水に落ちる…が、起き上がり小法師のように **ぷかっと浮かんで葉に戻る** 演出を入れる（達磨らしさ）
- 戻るたびに残り回数が減る。【未決定】回数（仮：**3回**。画面左上に小さな達磨のアイコンで表示）
- 回数がなくなったらゲーム終了 → 結果画面
- 戻った直後の2秒間は、ぶつかっても転覆しない（点滅などで分かるように）

### 4.5 終わり方：エンドレス（決定）
- 岸には着かない。転覆できる回数がなくなるまで、どこまで進めるかを競う
- スピードと難しさは上がり続けるが、ある距離から先は上限で止める（人の反応で避けきれない速さにはしない）。上限の距離・速さは遊んでみて調整する
- 長く進むと景色が少しずつ変わる（例：霧が晴れる→夕暮れ→夜の月明かり）。【未決定】変化の内容と、何里ごとに変えるか（仮：上の3段階をくり返す）

### 4.6 拾えるもの：念珠の珠（入れる・決定）
- 水面に珠がぷかぷか浮いて流れてくる。葉で触れると拾える（拾うとき小さく光って画面上部のカウントへ吸い込まれる）
- 珠は1個ずつ、または数個が弧を描くように並んで出てくる。並びをなぞるように動くと気持ちよく拾える配置にする
- 拾った珠は、達磨の足元で少しずつ連なっていき、念珠が編まれていく様子が見える
- **108個で一連の念珠が完成**。完成の瞬間に親珠（大きめの珠）と房が付き、達磨が念珠を手に掛ける演出。カウントは0に戻り、完成数が1増える
- 障害物の近くほど珠が多めに出る（危険を冒すと得をする作り）
- 転覆しても拾った珠は減らない
- 【未決定】念珠完成のご褒美（仮：転覆できる回数が1回回復。上限は最初の回数まで）
- 【未決定】珠の見た目（仮：木の珠＝茶色。水墨画の中の差し色として、衣の朱と並ぶ2つ目の色にする）
- 【未決定】完成数に応じて珠の種類が変わる要素（例：1連目は木、2連目は水晶…）を入れるか（仮：入れない。後で検討）

## 5. 見た目（アートの方向）

- 全体：**水墨画風**。白〜灰〜黒の濃淡が基本。色を使うのは達磨の朱の衣と、小さな差し色だけ
- 水面：墨を薄く流したような波紋。葉の後ろに細い航跡が残る
- 遠景：霧の中に山の稜線が、墨の濃淡で重なって見える
- 達磨：最初は単純な形（丸い体に朱の衣、顔は簡単な表情）で作る。凝ったモデルは後で差し替え可能にする
- 葉：細長い葦の葉。乗っている感じが伝わるよう、波でしなる
- 文字：明朝系または筆文字風の書体【未決定：使う書体（フォントのライセンス確認が必要）】
- 3Dモデルは最初はすべてプログラムで作る簡単な形で済ませる。外部のモデルや画像素材を使う場合は、使ってよいもの（ライセンス）かどうかを長岡に確認する

## 7. 音

- 【未決定：音を入れるか、どんな音にするか】
- 仮の方針：最初は **音なし** で作り、あとから次を足せるようにしておく
  - 川の流れの環境音
  - 岩にぶつかる音、水に落ちる音、起き上がる「ぽこっ」という音
  - 着岸時に鳴る鈴や木魚のような音
- 音は初期状態でオフにする（SNSから急に音が鳴らないように）。タイトル画面で切り替えられる

## 8. 動作の重さへの配慮

- スマホでもカクつかないことを優先する（目安：1秒あたり滑らかに動く表示＝60コマを目標、最低でも30コマ）
- 重い端末では自動で、水面の細かさ・霧・影などを軽くする
- 読み込み開始から遊べるまで、数秒以内を目標にする

## 9. 作る順番（ステップ）

各ステップが終わるごとに、実際にブラウザで遊べる状態にして報告すること。

### ステップ1：最小限で遊べる版
- 平らな水面、葉、達磨（簡単な形）
- 自動前進と左右操作（PC・スマホ両方）
- 岩だけの障害物と、ぶつかったら終了
- 距離の表示
- 確認方法：PCとスマホで開き、左右に動かして岩をよけられる。ぶつかると止まる

### ステップ2：ゲームとして成立させる
- 転覆と起き上がり（4.4）、残り回数
- 流木・渦・大波（4.3）、だんだん難しくなる仕組み
- 横向きの流れ（4.2）
- タイトル画面・結果画面、ベスト記録の保存
- 横持ちへの切り替えと見え方の調整（ステップ1の確認で判明した点を含む）
  - 横持ち前提にする（第2章）。縦持ち用に入れたカメラの切り替えは不要になる
  - スマホを縦に持ったときの案内表示（第2章の仮の方針）
  - 葉がどこにいても、**川幅の全体（両岸の間の岩と通り抜けの隙間）が常に画面に入る** ようにする
  - 画面の上3分の1ほどが何もない霧になっている → 前方の川がもっと見えるようにする（カメラの高さ・角度の調整など、方法は任せる）
- エンドレスの難易度上昇と上限（4.5）
- 念珠の珠：出現・拾う・カウント・108個で完成（4.6。演出は簡単なものでよい）

### ステップ3：見た目を整える
- 水墨画風の表現（第5章）、水面の波紋・航跡・霧・遠景の山
- 葉のしなり、達磨の傾き
- 珠が連なっていく様子と念珠完成の演出（4.6）
- 距離に応じた景色の変化（4.5）
- 重い端末向けの自動調整（第8章）

### ステップ4：仕上げ（共有と念珠店へのつながり）
- 結果画面の逸話の紹介文を、3.3の仮の文面に差し替える（あとで文面だけ差し替えやすくしておく）
- 結果画面に「Xで共有」ボタン：Xの投稿画面を新しいタブで開く。投稿文は第6章の例のとおり（距離と念珠の連数を入れる）。URLは公開URLが決まるまで仮の値でよく、1か所で差し替えられるようにする
- 結果画面に「長岡念珠店のサイトへ」ボタン：https://nagaokanenju.com を新しいタブで開く
- タイトル画面の右下「長岡念珠店」の表記も、同じサイトへのリンクにする
- OGP画像（リンクを貼ったときに出る画像）：仮画像を用意する。ゲーム画面（霧の川と葉に乗った達磨）にタイトル「一葦渡江」を重ねたもの。大きさは 1200×630。あとで長岡がAffinityで作った画像に置き換えられるようにする
- ページのタイトル・説明文（検索やSNSで表示される文）も設定する【仮】「一葦渡江 ― 葦の葉に乗った達磨大師と長江を渡るブラウザゲーム｜長岡念珠店」
- 確認方法：結果画面の各ボタンが正しいページを開くこと。OGPは公開後にXの投稿画面でURLを貼って確認する（公開前は確認できないので、未確認と報告すること）

### ステップ5：見た目の追加調整と音（ステップ3の確認で判明した点を含む）
- 川岸：いまは黒い直線の帯で、線路のように見える。**墨でにじませた岸辺や、葦の茂み** にして、水墨画の川らしくする【未決定：岸の描き方の細部（任せてよい）】
- 達磨：いまは赤い球のみ。**頭巾をかぶった衣の形と、ぎょろりとした目・髭の顔** が後ろ斜めからでも分かる達磨にする（簡単な形の組み合わせでよい。外部のモデルや画像は使わない）
- 音：第7章の決定に従う（決まるまで着手しない）
